How it knows what each session is doing

No screen reading and no terminal scraping. ClaudeDeck listens to the hooks Claude Code already provides.

  1. You run your own claude

    Each session is your installed Claude Code CLI in a real terminal, with your settings, CLAUDE.md, MCP servers and skills.

  2. A small hook reports the state

    On first launch ClaudeDeck adds one hook to ~/.claude/settings.json, after making a backup. It only acts in ClaudeDeck's own terminals.

  3. You get told when it's your turn

    Permission prompts, questions and finished turns show up in the sidebar, as notifications, on the Dock badge and in the menu bar.

What's inside

Everything you need to keep many sessions moving without switching between terminal windows.

Live status for every session
Running, needs permission, asking a question or your turn, for every session.
Allow or deny from anywhere
Answer permission prompts from the notification, the sidebar or the pane header.
Needs Attention at the top
Sessions waiting for you are listed first, with the project and what they're asking.
Side-by-side panes
Drag up to four sessions next to each other. Closing a pane keeps the session running.
Picks up after a restart
Open sessions come back with claude --resume. Oversized contexts get an automatic /compact.
Parallel worktree sessions
Run sessions in the same project, each in its own git worktree, so they never edit the same files.
Files panel with git history
Live file tree, change marks and per-file diffs. Drag a file into Claude to add it as @path.
Plain terminals too
A shell in the project folder, with an optional startup command like yarn start.
Widget and menu bar
A desktop widget and menu bar counters for what's waiting, running and done.
Projects, groups and iCloud
Pin projects, color-code groups, and optionally sync the list across your Macs.

What it is, and what it isn't

ClaudeDeck is a window around the Claude Code you already use.

ClaudeDeck isClaudeDeck is not
A session manager for your installed claude CLIA chat app or API client that replaces Claude Code
A dashboard driven by Claude Code's official hooksA tool that reads your screen or logs keystrokes
A local Mac app; nothing leaves your computerA cloud service, an account or telemetry
A shortcut that presses the key you would pressAn automation that approves permissions on its own

Billing, usage limits and sign-in stay with Claude Code.

Install

  1. Download the DMG

    Get the latest ClaudeDeck-<version>.dmg from GitHub Releases.

  2. Drag it to Applications

    The app is signed and notarized by Apple, so it opens without a Gatekeeper warning.

  3. Add your projects

    Pick a project folder and start a Claude session. ClaudeDeck sets up its hook on first launch.

  • Requires macOS 15 or later and Claude Code installed.
  • Available in English and Turkish.
  • Prefer to build it yourself? The README explains how.
